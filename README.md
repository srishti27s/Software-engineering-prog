# Software-engineering-prog
# 90-Day Software Engineer Progress

A structured 90-day learning journey focused on Data Structures and Algorithms, full-stack development, Generative AI, and software engineering fundamentals.

## Learning Goals

- Strengthen problem-solving skills using Java.
- Learn React, TypeScript, Node.js, Express, and database fundamentals.
- Build and deploy full-stack applications.
- Develop practical GenAI and Retrieval-Augmented Generation (RAG) applications.
- Practice testing, Git, Docker, CI/CD, and system design.
- Prepare for software engineering interviews.

## Day 1: Foundations

### Topics

- Big-O notation and complexity analysis
- Arrays, HashMap, and HashSet
- Two Sum
- Contains Duplicate
- Git and GitHub fundamentals

### Solutions

| Problem            | Approach | Time Complexity | Auxiliary Space |
| ------------------ | -------- | --------------- | --------------- |
| Two Sum            | HashMap  | O(n) average    | O(n)            |
| Contains Duplicate | HashSet  | O(n) average    | O(n)            |
